########## ROOT help
Soft Serve is a self-hostable Git server for the command line.

Usage:
  ssh -p 2223 localhost [command]

Available Commands:
  help                 Help about any command
  info                 Show your info
  jwt                  Generate a JSON Web Token
  pr                   Manage pull requests
  pubkey               Manage your public keys
  repo                 Manage repositories
  set-username         Set your username
  settings             Manage server settings
  token                Manage access tokens
  user                 Manage users

Flags:
  -h, --help   help for this command

Use "ssh -p 2223 localhost [command] --help" for more information about a command.

########## help pr create
Create a new pull request

Usage:
   pr create REPOSITORY --head <[REPO:]BRANCH> [--base <BRANCH>] [--title <TITLE>] [--body <BODY>] [flags]

Flags:
  -B, --base string    target branch to merge into (defaults to default branch)
  -b, --body string    description/body of the pull request
  -H, --head string    source branch to merge from (e.g. 'my-feature' or 'my-fork:feature')
  -h, --help           help for create
  -t, --title string   title of the pull request

########## help repo webhook create
Create a repository webhook

Usage:
   repo webhook create REPOSITORY URL [flags]

Flags:
  -a, --active              whether the webhook is active (default true)
  -c, --content-type json   content type of the webhook payload, can be either json or `form` (default "json")
  -e, --events strings      events to trigger the webhook, available events are (branch_tag_create, branch_tag_delete, collaborator, push, repository, repository_visibility_change)
  -h, --help                help for create
  -s, --secret string       secret to sign the webhook payload
